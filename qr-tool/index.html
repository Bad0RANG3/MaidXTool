—

· 本页面由 Node 静态服务托管，访问 http://127.0.0.1:8787 使用。
· 左侧①的解析结果就是你要发给机器人的二维码字符串（/b50 或 /fp）。
· 点击「再跑一次 qr_api」会把字符串发给后端换 token（一次性，会记录到 qr-tool/decoded_qr.log）。
· 二维码换 token 是一次性的，接口返回的 userID / token 请勿外泄。
